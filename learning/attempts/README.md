# Project 1 Preserved Attempts

Attempts preserve completed guided exercises and module tests as review material and portfolio evidence. They are separate from clean originals in `learning/starters/` and unfinished local work in `learning/working/`.

Create an attempt from a completed working notebook with `python scripts/save_attempt.py <module>` or add `--test` for a module test. The command preserves recorded outputs and refuses to overwrite an existing attempt unless `--force` is supplied.
