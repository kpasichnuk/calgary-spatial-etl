# Practice Notebook Starters

These notebooks are clean, version-controlled originals for guided practice. Do not record personal work directly in this folder.

Create an ignored working copy with:

```bash
python scripts/reset_notebook.py <module>
```

Complete exercises in `learning/working/`. After reviewing the finished notebook, preserve it in `learning/attempts/` with:

```bash
python scripts/save_attempt.py <module>
```

The reset command clears execution state in the working copy. The save command preserves answers and outputs in the completed attempt.
