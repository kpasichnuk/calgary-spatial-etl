# Analysis Module Tests

Each analysis module has a 25-point end-of-module notebook test. The recommended progression threshold is 20/25.

Tests evaluate both executable technique and written spatial reasoning. A calculation with an unsupported interpretation does not earn full credit.

Expected evidence includes:

- explicit units and spatial predicates
- predictions before results
- reconciled counts
- inspected edge cases
- distinctions between supported and unsupported claims
- recommendations for additional evidence
