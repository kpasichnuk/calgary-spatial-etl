# Analysis Tests

Automated tests will be added with reusable analysis code.

Expected coverage includes:

- known point-in-polygon assignments using synthetic geometries
- boundary and unmatched-point behavior
- preservation of zero-count communities
- count reconciliation
- area-unit conversion
- rejection of non-positive denominators
- stable output schema and identifiers
- parity between Python and PostGIS summaries where both are implemented

Module tests assess learner understanding. This folder is for automated software tests.
