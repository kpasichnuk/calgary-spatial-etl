# Analysis Outputs

Generated analysis outputs belong here and should be reproducible from QA-approved Project 1 data.

Planned outputs include:

- community transit-stop summary tables
- maps or figures
- validation reports
- interpretation-ready extracts

Generated files should not be committed by default. Add explicit `.gitignore` patterns when implementation begins. Commit only small, intentional portfolio artifacts whose data licence, reproducibility, and purpose are documented.

An output must record or inherit:

- source snapshot or database state
- analysis code version
- CRS and units
- spatial predicate
- measure and denominator
- generation timestamp

Do not manually edit a generated result to correct an analytical or ETL defect.
